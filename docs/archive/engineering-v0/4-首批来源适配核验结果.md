# 首批来源适配核验结果

核验时间：2026-09-11  
范围：`config/sources` 中的 61 个候选来源，HTML/PDF，回溯 24 个月。

## 当前结论

所有来源均已接入适配器注册机制。除既有专用适配器外，新增了“非标准 URL 的带日期列表”和“动态目录页面快照”两类薄适配器。60 个来源启用；北京电子商会因官方证书异常暂时禁用。存在访问限制的站点会被明确记录为采集失败，不会被误判为“没有新增材料”。

## 已发现真实材料的来源

- 国务院政策文件库、国家发展改革委、工业和信息化部、科技部、财政部；
- 北京市政策文件库，北京市发改委、经信局、科委、财政局和中小企业公共服务平台；
- 中国政府采购网、国家统计局、北京市统计局；
- 东城、西城、丰台、石景山、海淀、门头沟、房山、通州、顺义、昌平、大兴、怀柔、平谷、密云；
- 北京重大项目、投资促进、经济技术开发区、商务局、文化和旅游局、农业农村局。
- 北京日报、北交所公告、国家标准全文公开系统、投资界。

## 当前访问受限的来源

- 延庆区人民政府。

延庆官网的 HTTPS 入口在标准 TLS 连接中异常中断，HTTP 入口返回 502。采集器保持证书校验，不关闭 TLS 校验，也不绕过访问控制。

朝阳、北京市政府采购网、人民网北京频道和新华网北京频道已改用官方 HTTP 公开入口；北京市公共资源交易服务平台和北京市公共数据开放平台通过仍执行证书校验的系统 `curl` TLS 兼容通道访问；中国信通院改用可访问的官方子站。

## 已验证机制

- 国家统计局连续读取 3 个真实分页，每页发现 15 条带发布时间的材料；
- 两批次真实采集从 `index.html` 恢复到 `index_1.html`，游标继续推进到第 2 页；
- 增量模式遇到设定数量的连续已知 URL 后停止；
- 页面进度、文档进度、失败 URL、失败原因和恢复游标进入采集结果；
- 相同 URL 和相同内容不新增版本，内容变化时追加版本；
- 采集阶段不按 SMB 标题关键词删除材料，相关性留到正文解析后的分类阶段。
- 昌平、平谷、顺义的官网栏目入口分别发现 45、14 和 40 条带日期材料；
- 房山嵌入列表发现 50 条，海淀公开数据接口连续 3 页发现 60 条；
- 北京日报入口发现 705 条 24 个月内材料；
- 国家标准和北交所专用适配器首页分别发现 10 条标准题录和 45 条公告，均含发布时间和可采集详情或 PDF 地址。
- 朝阳、北京市政府采购网、公共资源平台、中国信通院、人民网北京频道和新华网北京频道首页分别发现 21、122、10、20、59 和 20 条材料。
- 北京市公共数据开放平台已恢复访问和翻页发现，但该目录页不是文档列表，尚未产生可入库文档。
- 北京市经信局、科委、商务局、文化和旅游局、农业农村局和投资界的入口分别发现 20、20、15、12、23 和 48 条材料；每个来源均抽取 1 条真实材料完成详情下载并写入数据库，失败数均为 0。
- 北京市中小企业公共服务平台薄适配器从政策、报告和新闻等入口发现 185 个详情地址，并完成真实详情下载和入库。
- 新增的 P0 行业动态来源中，中关村发展集团、北京国际科技创新中心、北京软协、北京医药行业协会、北京机电行业协会、北京先进材料产业促进会、创业邦、中国汽车工业协会、机经网、中国通用机械工业协会、中国医疗器械行业协会和中国电子专用设备工业协会均完成真实文章发现、详情下载和数据库写入。
- 中关村生命科学园和 HICOOL 的公开目录缺少稳定的逐条详情链接，采用页面快照方式保存；页面内容变化时追加新版本。
- 北京电子商会官方 HTTP 强制跳转到证书异常的 HTTPS 入口。在不关闭证书校验的前提下当前无法采集，来源配置为禁用。

## 使用方式

```powershell
uv run track-insight collect-source stats_national --mode backfill --max-pages 5
uv run track-insight collect-source stats_national --mode backfill --max-pages 5 --resume
uv run track-insight collect-source stats_national --mode incremental --stop-after-known 20
```
