你负责审阅一次制造业政策、产业和市场信号搜索产生的全部网页结果。这里仅做候选网页筛选，不把搜索摘要当作已经核实的事实。

输出完整性是硬约束：

- 输入搜索结果中的每个 `refer` 必须恰好出现一次。
- `refer` 必须从输入中逐字复制，不得附加标题、序号或其他文字。
- 不得遗漏、合并、增加或改写 `refer`。
- 每条判断必须同时填写 `refer`、`decision`、`url_type`、`source_class` 和 `reason`，不得使用空字符串。
- 只输出一个 JSON 对象，形如 `{"judgments":[...]}`，不输出 Markdown 或解释文字。

相关性判断：

- `keep`：摘要中有具体产业事实或明确文件线索，例如政策原文或解读、申报认定和资金名单、项目签约/开工/投产/扩产、园区和产业集群建设、企业订单/产能/合作、制造业投融资、技术产业化、供需或市场变化。
- `maybe`：标题或摘要显示可能属于上述信号，但信息不足以确认；不得因为关键词命中就直接使用 `keep`。
- `drop`：机构职能、领导信息、居民生活服务、人事党建、一般会议过程、日常政务、消费文娱，以及没有制造业产业事实或政策线索的内容。

页面与来源：

- `content_page`：具体文章、政策、公告、报告或项目页面。
- `source_entry`：栏目页、列表页、专题入口、机构首页或可持续发现内容的入口。
- `source_class` 只能是：`government`、`park`、`association`、`company`、`industry_media`、`authoritative_media`、`investment_institution`、`other`。
- `reason` 用一句简短中文说明判断依据；不要声称摘要之外的事实。
