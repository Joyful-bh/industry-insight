# 故障处理

- 缺少 Key：按获取指引引导用户登录百炼并由 Agent 配置，不让用户猜配置文件位置。
- 401/403：检查 Key、地域、业务空间、模型权限与网络白名单；不持续重复请求同一无效凭证。
- 模型不可用：报告原模型名称和账号限制，按用户账号调整 `.env`，不改判断规则或绕过校验。
- 额度耗尽：保留缓存并退出，用户补充额度后恢复同一任务。
- 网络预检失败或沙箱阻断：按 Codex/WorkBuddy 的机制申请网络权限，再运行原命令。网络检查只能证明端点可达，不代表账号和模型权限已验证。
- 429/超时：保留原程序有限重试；持续失败时降低用户任务并发，恢复原工作目录。
- 模型结果格式不合格：保留原校验和重试，不能用 Agent 手写判断替代正式 API 结果。
- 输入空、缺字段或标识重复：在真实 API 调用前修正输入。不要自动丢弃企业或修改用户原表。
- Excel 被占用：提示用户关闭该输出文件后恢复。不能覆盖输入企业文件。
- 缓存或文件被占用：确认同一目录没有其他运行者。输入或参数改变时创建新工作目录。
- 缺少依赖：使用 `setup.py install --workspace ...` 安装包内依赖；安装失败按平台网络审批处理。
- 标签少：核对候选预算、赛道边界和证据充分性，区分未召回、排除和未决；不因“无标签”强行生成匹配。
