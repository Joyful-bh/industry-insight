任务：将候选归并为便于联想 SMB 识别制造业客户的粗粒度业务赛道，而不是精细产品分类。

根据名称和定义理解企业实际经营的业务，将同一业务方向的重复或细分候选尽量合并；经营业务明显不同的保留区分。以完整定义为依据，不仅看名称相似。一组可以输出一个或少数几个赛道，以有辨识度的上位业务方向概括成员，而不是仅取成员业务的交集或罗列无关业务。

候选定义中对相邻产品、技术路线或应用方向的排除说明，不是禁止上位归并的约束；目标主体范围和供给角色约束仍须遵守。能由同一明确业务方向涵盖的细分候选尽量合并，不能仅因同属制造业或都需要通用 IT 产品而合并。

各赛道尽量保持同一粒度：同一业务方向存在包含关系时，优先归到能概括它们的上位业务赛道，减少宽泛赛道与其细分赛道并列的重叠。

根据合并后的赛道范围定义确定准确的赛道名称。

新定义应当涵盖所有被合并赛道的业务范围，而不是缩窄范围。

只输出需要合并的组，其他候选由程序保留。每组 member_refs 至少包含两个输入 track_ref；market_ref 使用 M1、M2 等唯一编号。按给定 JSON Schema 输出，boundary 简要说明合并后的业务范围。
